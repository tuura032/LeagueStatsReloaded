# Screenshots

Visual reference for what the site actually looks like, keyed by the short
commit hash it was built from. Not auto-generated by CI — taken manually
(or by an agent) with Playwright when it's useful to have a before/after,
or as a baseline for a session that hasn't seen the rendered site.

Each `<short-hash>/` folder has one file per `{page}-{theme}-{viewport}.png`:

- pages: `home`, `playoffs`, `graph`, `careers`, `rivalries`
- theme: `light`, `dark`
- viewport: `desktop` (1440x900), `mobile` (390x844, iPhone-ish)

## Regenerating

```
python -m http.server 8934 --directory docs &
OUT_DIR=screenshots/$(git rev-parse --short HEAD) python shoot.py
```

`shoot.py` isn't checked in (it's a one-off scratchpad script) — recreate it
from the pattern above if needed: launch Playwright chromium, iterate
theme x viewport x page, `context.new_context(color_scheme=..., viewport=...)`,
`page.screenshot(path=..., full_page=True)`.

Old folders aren't pruned automatically — delete ones that are no longer a
useful reference point (e.g. superseded by a later redesign) when you notice
this directory getting large.
